<objective>
Migrate the exact authorized local target to the Phase 33 schema, then build/import the complete grammar curriculum and independently validate both transitions.

Purpose: Production import must never run against an unmigrated, ambiguous or production target.
Output: Migration proof, grammar artifact pairs, production manifest pair and import-validation pair.
</objective>

## Anti-Goals
- No production target, alternate migration/head, provider/TTS call, personal processing, readiness, activation, publication, APKG or delivery.

- Migration result must pass before build/import. All 12 artifacts are six create-only atomic output+sidecar pairs with no hidden outputs.

## Evidence Contract
- Exact migration file/head/prestate/poststate/parity/no-write retry and exact curriculum/import/CAS/retry checks must all pass.

- Assuming Plan 07 test migration changed the authority target, running build before reconnect/parity, treating already-at-head as a second write, or trusting producer snapshots.

- Stop on target or graph ambiguity, production locator, file/hash drift, missing rollback proof, unexpected data mutation, output widening or any failed independent counter.

## Approval Gates
- Consume only Plan 12's exact local migration/import/output powers; no additional human quality or listening gate is introduced.

## Leverage Review
- Second pass independently compares migration pre/post/retry and curriculum/asset/DB/manifest identities before any completion claim.
