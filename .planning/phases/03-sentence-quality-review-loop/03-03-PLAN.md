## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| generated text bundle → validation engine | Untrusted model/provider output is evaluated before becoming learner-facing text |
| validation result → persisted review state | Confidence and failure reasons determine whether text is shipped or flagged |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-08 | T | `src/multilang/services/text_validation.py` | mitigate | Enforce deterministic lemma presence, length, and banned-pattern checks so malformed or irrelevant sentences cannot pass on provider confidence alone per D-07. |
| T-03-09 | I | `src/multilang/services/text_validation.py` | mitigate | Reject translations copied from definitions or missing sentence alignment so headword glosses cannot masquerade as sentence translations per D-04. |
| T-03-10 | D | `src/multilang/services/generate_text_items.py` | mitigate | Cap the repair loop at one retry and persist review-required state after the second failure to avoid runaway retries per D-06. |
| T-03-11 | R | `tests/services/test_generate_text_items.py` | mitigate | Add tests proving accepted, repaired, and review-required outcomes so later refactors cannot silently remove review routing. |
</threat_model>
