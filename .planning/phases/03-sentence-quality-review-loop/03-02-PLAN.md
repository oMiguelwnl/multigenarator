<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| grounded lexical candidate → text-generation adapters | Persisted lexical meaning becomes model/provider input |
| generated sentence → translation adapter | Untrusted model output becomes the source of learner-facing translation |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-05 | T | `src/multilang/services/text_generation.py` | mitigate | Accept only grounded lexical candidates and pass explicit typed fields to the sentence adapter so raw submitted strings do not bypass lexical grounding per D-02. |
| T-03-06 | I | `src/multilang/services/text_generation.py` | mitigate | Call the translation adapter with the final generated sentence and translation target only, preventing definition text from leaking into the translation value per D-04. |
| T-03-07 | R | `tests/services/test_text_generation.py` | mitigate | Use fake adapters in tests to lock the generation→translation call order and provenance payload without depending on live model behavior. |
</threat_model>
