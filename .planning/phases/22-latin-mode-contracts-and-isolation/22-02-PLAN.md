| CLI args → LatinGenerationRequest | User-supplied source pack version crosses into metadata output. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-22-04 | Tampering | `generate-latin-mvp --source-pack-version` | mitigate | Pydantic validation from `LatinGenerationRequest` rejects blank versions; tests cover override behavior. |
| T-22-05 | Repudiation | CLI metadata output | mitigate | Emit stable `key=value` lines for language, variant, source type, pack version, and card count. |
| T-22-06 | Denial of Service | Latin item-key generation | accept | Generates a fixed 50 keys in memory by contract; no unbounded user count is accepted. |
</threat_model>
