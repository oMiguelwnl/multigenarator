<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| local CLI subprocess → app | Native eSpeak execution can fail or return unexpected files. |
| sample manifest → human review | Metadata could misrepresent provider support if statuses are too permissive. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-27-02-01 | Tampering | eSpeak output path | mitigate | Validate output path existence, nonzero byte size, and command output path equality before creating approved candidate metadata. |
| T-27-02-02 | Spoofing | Azure candidate status | mitigate | Hard-code Azure multilingual as experimental/blocked unless explicit sample artifacts are supplied and still require playback review. |
| T-27-02-03 | Information Disclosure | subprocess errors | mitigate | Return sanitized error summaries without env vars or absolute PATH dumps. |
</threat_model>
