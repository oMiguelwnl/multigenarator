## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Multilang→WebDAV | Outbound authenticated PROPFIND/GET sends credentials to remote server. |
| WebDAV→parser cache | Untrusted remote XML/body enters local process and private cache. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-04 | I | `UrllibWebDAVTransport` | mitigate | Construct auth header internally and never expose headers in DTOs/errors. |
| T-14-05 | T | `list_exports()` XML parser | mitigate | Parse only expected WebDAV XML fields; invalid XML raises `malformed_response`. |
| T-14-06 | T | `fetch_export()` cache write | mitigate | Validate status, suffix, and non-empty body before atomic write. |
| T-14-07 | D | WebDAV network calls | mitigate | Apply `webdav_timeout_seconds` to transport request. |
</threat_model>
