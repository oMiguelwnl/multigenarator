| Boundary | Description |
|----------|-------------|
| private highlight storage -> prompt builder | Private reading text crosses from local persistence toward provider input. |
| provider exception -> CLI/report output | External adapter failures may include prompt content or private data. |

| T-12-04 | Information Disclosure | `provider_text_adapters.py` prompt/error metadata | mitigate | Prompt only with redacted context, store safe source metadata, and redact provider exception strings before fallback metadata. |
</threat_model>
