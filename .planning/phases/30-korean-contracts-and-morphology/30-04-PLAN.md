## Requirements Covered

- **KMODE-01:** all three existing source modes route canonical `ko` identity through shared ingestion/persistence.
- **KMODE-02:** Korean branches are additive and preserve every existing source path/privacy contract.
- **KNLP-01:** morphology evidence is bound to source lemma/POS/sense before becoming a grounded candidate.
- **KNLP-02:** highlight extraction is morpheme-aware, homograph-safe, compound-aware, and fail-closed.

## Must-Haves

1. Source records, not Kiwi or an LLM, decide `sense_id`.
2. All three modes persist one identity shape.
3. Korean highlights bypass forbidden generic heuristics.
4. Preview and ingestion agree because they share a resolver contract.
5. Private reading data remains private.

## Anti-Goals

- No production data or downstream pedagogy.
- No provider-facing generation wiring.
- No audio/template/export changes.
- No broad refactor of generic extraction or grounding.

## Hard Boundaries

- NFC-analyze every explicit source lemma with the same pinned adapter/fingerprint used for the surface, project its full ordered one-eojeol lexical signature, and bind only by exact signature plus normalized source POS.
- Require each top-two surface alternative to select exactly one record and require both selections to be the same lemma/POS/sense.
- Never derive a source dictionary lemma by concatenating token forms or stripping/appending Korean suffixes/endings.
- Preserve the locked top-two agreement and analyzer fingerprint.
- Treat missing source record, missing sense, POS conflict, ambiguity, OOV, or analyzer failure as non-passing.
- Keep raw highlight records only in the existing private repository.

## Evidence Contract

- Grounding tests use reviewed/synthetic source records and prove each source mode's resolved and blocked states, including a real-Kiwi `공부하다` source-lemma/full-signature binding, top-analysis record disagreement, and matching morphology with no source record.
- Highlight tests cover one-syllable nouns, attached particles/endings, compound predicates, homographs, NFC/NFD, ordering, duplicates, unavailable/ambiguous results, and privacy.
- Preview tests prove count agreement and content-free errors.
- Ingestion tests use a real disposable repository lifecycle and assert persisted identity, hashes/indexes, and no raw excerpts in public candidate storage.

## Common Pitfalls

- Looking up the attached surface eojeol rather than analyzer lemma candidates.
- Reconstructing `공부하다` by concatenating `공부` + `하` + `다`, stripping an ending, or appending a suffix instead of analyzing the explicit source lemma and comparing complete signatures.
- Calling `_ground_frequency_seed_candidate()` for Korean and treating a generated seed as authoritative.
- Adding `KO` to `_STOPWORDS` while still using regex/NFKC/length filtering.
- Resolving highlight morphology twice with different adapter instances.
- Putting `first_highlight_id` alongside raw text/path rather than existing hash/index provenance.

## Stop-And-Challenge

- Stop if exactly-one source identity cannot be established.
- Stop if a Korean path reaches generic `_lemma_key`, `_is_usable_token`, suffix, or whitespace matching.
- Stop if preview needs provider/runtime secrets or public persistence of private reading content.
- Stop if non-Korean extraction behavior changes outside explicit regression fixes caused by this work.

## Approval Gates

- Synthetic/reviewed fixtures prove contracts only and are not approved production data.
- No provider exposure, data redistribution, or private-context expansion is approved.
