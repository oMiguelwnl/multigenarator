## Requirements Covered

- **KHAN-01:** Korean note identity/template/media joins and all-format structural export.
- **KHAN-02:** hidden persisted graph evidence and false-i+1 pre-write refusal.
- **KPRO-01:** exact nine fields and media survival through APKG/CSV/TSV.
- **KPRO-02:** source active-rule/strict evidence gates every output.

## Must-Haves

1. IDs, schemas, names, GUIDs, tags, and ordering are deterministic.
2. All source/review/media/template validation completes before output.
3. Every format contains resolvable exact bytes, not dangling tags.

## Anti-Goals

- No generic exporter/runtime/DB changes, provider calls, approval bypass, or rendered visual claim.

## Hard Boundaries

- Use separate `HangulExportRow` and `KoreanPronunciationExportRow`.
- Resolve the fixed production active pointer once per operation and use only that frozen snapshot; dependency injection is a private test-only composition seam, not a public service or CLI path override.
- Plain text is escaped/validated; only designated bounded Anki media tags remain HTML.

## Evidence Contract

- Test fixtures generate deterministic non-empty media only under `tmp_path`, use test IDs, and never touch the active pointer or immutable production snapshots.
- APKG tests inspect ZIP media map and extracted collection SQLite.
- CSV/TSV tests parse headers/rows with `csv.reader` and resolve every media reference through copied bytes/checksums.
- Every failure asserts target absence.

## Common Pitfalls

- Creating the output directory before review/media validation.
- Hashing mutable translation/template/media filename into GUIDs.
- Mixing two schemas in one table.
- Writing sound tags without media bytes.

## Stop-And-Challenge

- Stop on ID collision, generic-surface requirement, unsupported media, dangling reference, or non-atomic output behavior.

## Approval Gates

- Successful transient fixture export proves machinery only; production remains blocked pending Plan 31-11 canonical evidence/preparation and Plan 31-12 authorization/activation.
