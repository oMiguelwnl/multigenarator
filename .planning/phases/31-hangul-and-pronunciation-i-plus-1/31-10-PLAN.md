## Requirements Covered

- **KHAN-01/02:** fixed Hangul readiness/export and strict-evidence command flow.
- **KPRO-01/02:** fixed pronunciation readiness/export and complete P0-P13 command flow.

## Must-Haves

1. Command names/options are exact and pathless except export destination.
2. Complete temporary success/refusal/drift integration passes.
3. Prepared verification is demonstrably strictly read-only.
4. All six temporary artifacts receive deep inspection.
5. Lock/Python 3.12/full-suite closure passes automatically before the checkpoint.
6. No canonical mutation or provider construction occurs.

## Anti-Goals

- No real evidence/checkpoint, canonical state, provider call, publication, or observed visual/playback claim.

## Hard Boundaries

- Family values are exactly `hangul` and `pronunciation`; format values are exactly `apkg`, `csv`, and `tsv`.
- `inspect-exports` has one fixed root and filenames; it is not an arbitrary artifact inspector.
- Private test constant injection is not CLI-reachable.

## Evidence Contract

- CLI signature tests reject every source/root/path/import/bypass/test-hook option.
- Integration tests cover validation-first zero-write drift plus complete temporary success for receipt, prepare, activation, provenance, and six exports.
- Prepared-verifier tests poison all write/recovery primitives and cover exact success plus missing/altered zero-write failure.
- Deep inspection covers APKG SQLite/media and tabular fields/sound refs/media/checksums/IDs/root hashes.
- Automatic closure runs `uv lock --check`, an isolated Python 3.12 probe, and full offline pytest before Plan 31-11.

## Common Pitfalls

- Leaving command names as implementer discretion.
- Testing services directly but not Typer routing/options/exit codes.
- Treating temporary exports as canonical production proof.
- Constructing providers through app startup.

## Stop-And-Challenge

- Stop on any arbitrary source path, canonical fixture leak, provider construction, or uninspected output.

## Approval Gates

- None. Plan 31-11 is the first checkpoint and may start only after this plan succeeds.
