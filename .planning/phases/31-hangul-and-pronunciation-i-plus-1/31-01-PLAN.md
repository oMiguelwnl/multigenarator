## Requirements Covered

- **KHAN-01:** modern-Jamo identity and syllable construction contracts.
- **KHAN-02:** explicit bootstrap, stored evidence, NFC, and recomputed one-unknown enforcement.
- **KPRO-02:** shared concept graph, active-rule accounting, and fail-closed strict sequencing.

## Must-Haves

1. Learner display glyphs cannot weaken canonical Korean identity.
2. Modern Hangul algorithmic composition is exhaustive and deterministic.
3. Graph and strict evidence are executable invariants, not trusted labels.

## Anti-Goals

- No source inventory, media, human review, template, exporter, CLI, database, or provider work.

## Hard Boundaries

- Extend `domain/korean.py`; do not create a second Korean domain module.
- Use stdlib `unicodedata` and `graphlib`; add no package.
- H0 is explicit data and each H0 entry must pass the same one-unknown calculation before becoming known.

## Evidence Contract

- Tests must be written first and observed failing for each new API.
- Exhaustively round-trip all 19 x 21 x 28 modern syllable combinations.
- Mutation cases must fail with controlled, content-free reasons.
- Existing Korean domain tests must pass unchanged.

## Common Pitfalls

- Calling NFKC on standalone display glyphs.
- Initializing `known_before` with every bootstrap concept.
- Trusting `unknown_concept_ids` from JSON.
- Letting an `approved` flag rescue an invalid graph.

## Stop-And-Challenge

- Stop on any need to relax Phase 30 canonicalization, infer positional identity, or hide multiple rules behind one concept.

## Approval Gates

- No linguistic, pedagogical, or media approval may be created by these deterministic tests.
