| Boundary | Description |
|----------|-------------|
| user input → GenerationRequest | User-provided CLI/source strings enter typed domain validation. |
| source profile → downstream generation/export | Source-specific privacy/export decisions will control later prompt and artifact behavior. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-01 | Tampering | `GenerationRequest.source_type` | mitigate | Validate against the explicit `SourceType` keys instead of implicit string comparisons. |
| T-09-02 | Information Disclosure | `get_source_profile` errors | mitigate | Error messages include only source-type keys, never file contents, raw highlights, paths, or credentials. |
| T-09-03 | Elevation of Privilege | highlight profile defaults | mitigate | `kindle-highlights` is represented but not CLI-selectable in this plan; Phase 11 must intentionally wire it. |
</threat_model>
