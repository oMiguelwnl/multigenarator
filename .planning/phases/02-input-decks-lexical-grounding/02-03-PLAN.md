## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user-provided text file → parser | Untrusted file content becomes normalized lexical input |
| Kaikki cache → lexical candidate fields | External lexical data becomes learner-facing definitions and IPA |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-09 | T | `src/multilang/services/word_list_parser.py` | mitigate | Parse only UTF-8 plain text, preserve line numbers, and emit explicit duplicate/blank diagnostics so malformed input cannot silently alter the requested list. |
| T-02-10 | I | `src/multilang/services/lexical_grounding.py` | mitigate | Never fabricate IPA and always record provenance, so missing pronunciation data cannot masquerade as authoritative output. |
| T-02-11 | T | `src/multilang/services/lexical_grounding.py` | mitigate | Distinguish `pending` custom failures from `backfill_required` frequency failures so the system does not silently swap user-requested items with unrelated words. |
