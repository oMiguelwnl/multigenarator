## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI input → local lexical bootstrap | Untrusted operator-supplied archive paths control what lexical cache gets built for runtime use |
| lexical prerequisite check → ingestion runtime | Cache state determines whether generation is allowed to proceed or must abort early |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-02-gap-02 | R | `src/multilang/cli.py` | mitigate | Print an explicit lexical-data prerequisite diagnostic before ingestion starts when the requested language index is missing, so clean-runtime failures are auditable instead of silently degrading to hollow output. |
| T-02-gap-03 | D | `tests/integration/test_lexical_job_flow.py` | mitigate | Add clean-runtime integration coverage for both bootstrap-success and missing-data failure paths so shipped CLI regressions are caught before phase re-verification. |
| T-02-gap-04 | I | `docs/lexical-data.md` | mitigate | Document that local Kaikki archives are operator-supplied inputs and that runtime reuses the derived cache, avoiding hidden assumptions about bundled lexical data. |
