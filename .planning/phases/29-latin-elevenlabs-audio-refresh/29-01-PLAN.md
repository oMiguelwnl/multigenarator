# Phase 29: Latin ElevenLabs Audio Refresh - Plan 01

## Objective

Replace the current Latin MVP eSpeak NG audio pack with a reviewed higher-quality provider path, preferably ElevenLabs, while preserving the approved 50-card Latin export contract and removing project-level eSpeak dependence only after replacement evidence passes.

## Context

- `.planning/ROADMAP.md` Phase 29 defines AUDR-01 through AUDR-05 for the Latin audio refresh.
- `.planning/REQUIREMENTS.md` marks FineVoice active integration and system-level eSpeak uninstall as out of scope.
- `.planning/research/29-RESEARCH.md` confirms the existing ElevenLabs adapter is the preferred integration surface and FineVoice is research-only.
- `src/multilang/services/latin_audio.py` owns audio manifest validation and export readiness.
- `src/multilang/services/latin_export.py` already blocks export unless the audio manifest is ready.
- Current worktree has unrelated user changes in Latin export/template quick-task files; executors must read before touching overlapping files and preserve unrelated edits.

## Requirements Covered

- AUDR-01
- AUDR-02
- AUDR-03
- AUDR-04
- AUDR-05

## Must-Haves

1. Representative Latin samples promote ElevenLabs only after user playback approval; FineVoice is documented as future research only.
2. The committed Latin MVP audio manifest and 100 media files are refreshed with approved non-eSpeak provider metadata.
3. Validators and tests fail closed for stale eSpeak dependence, unapproved audio, text mismatch, unsafe paths, missing media, and source-pack drift.
4. Latin APKG/CSV/TSV export works with the refreshed media without changing field order or existing-mode isolation.
5. Project-level eSpeak dependencies are removed only after the replacement manifest, media, tests, and export evidence pass; system eSpeak remains untouched.

## Anti-Goals

- Do not activate FineVoice.
- Do not add a second Latin deck scale or broader provider abstraction rewrite.
- Do not rewrite shipped Phase 22-28 historical planning artifacts just to remove mentions of eSpeak.
- Do not uninstall or instruct the user to uninstall eSpeak NG from the operating system.

## Hard Boundaries

- Keep Latin source pack, curation identities, translations, grammar, card count, and Anki field order stable.
- Keep secrets and private file paths out of committed artifacts and public diagnostics.
- Keep live provider calls explicit and review-gated.
- Preserve unrelated dirty worktree changes unless they directly block this phase.

## Evidence Contract

- Service tests prove ElevenLabs-first Latin sample/full-pack generation can be tested with fakes and does not wire FineVoice actively.
- A human playback review artifact records the approved provider, voice, model/version, pronunciation policy, review status, reviewer, timestamp, and sample paths.
- Integration evidence loads committed real refreshed manifest/media and proves all 50 word plus 50 sentence artifacts are approved, source-aligned, and export-ready.
- Export evidence builds APKG/CSV/TSV from refreshed assets and verifies 50 cards plus 100 packaged media references.
- A post-replacement grep or targeted test proves active project code/tests/docs no longer require eSpeak NG, while historical phase archives may still mention it.

## Common Pitfalls

- Treating ElevenLabs as approved before listening to samples.
- Leaving `espeak-ng` as an allowed current provider or expected provider count in tests after refreshing assets.
- Calling ElevenLabs during export instead of persisting generated media.
- Deleting old media before replacement APKG evidence passes.
- Letting FineVoice move from research candidate to runtime provider without a separate decision.

## Stop-And-Challenge

- Stop if ElevenLabs samples are rejected or provider credentials/quota cannot generate a representative sample set.
- Stop if a replacement requires changing learner-facing Latin fields, source text, translations, grammar, or export shape.
- Stop if there is pressure to remove system eSpeak NG before project references are eliminated.

## Approval Gates

- Human playback approval is mandatory between sample generation and full-pack promotion.
- Live ElevenLabs generation beyond tests must be explicitly invoked with configured credentials and quota awareness.
- Deleting or replacing committed media is allowed only after refreshed media and manifest validation exists in the same task.
