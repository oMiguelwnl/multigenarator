<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI arguments → orchestration service | Untrusted operator input controls job creation and overwrite paths |
| persisted repository state → orchestration service | Stored state influences whether work is resumed, skipped, or blocked |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-job-01 | T | `src/multilang/cli.py` | mitigate | Restrict `--language` and `--source` through Typer + shared enums so malformed CLI input cannot create undefined job modes. |
| T-01-job-02 | T | `src/multilang/services/generate_job.py` | mitigate | Call `validate_resume_state` before resume and abort on `ResumeDiagnostic`, preventing corrupted persisted state from changing outputs. |
| T-01-job-04 | R | `src/multilang/services/input_fingerprint.py` | mitigate | Compute deterministic fingerprints and `run_key` values so rerun/skip decisions are reproducible and reviewable. |
| T-01-job-07 | E | `src/multilang/cli.py` | mitigate | Require interactive confirmation or `--yes-overwrite` before any overwrite path reprocesses existing outputs per D-08. |
</threat_model>
