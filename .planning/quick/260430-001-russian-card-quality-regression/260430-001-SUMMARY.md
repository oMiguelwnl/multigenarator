# Quick Task 260430-001 Summary

## Outcome

Fixed the observed Russian frequency-card quality regression in the real generation path.

## Changes

- Added Kaikki duplicate scoring so regenerated indexes prefer substantive lexical entries over form-of, abbreviation, symbol, and letter records.
- Added frequency grounding filters so stale existing indexes no longer promote morphology-only, abbreviation, letter, or uppercase Russian duplicate records into card candidates.
- Added a non-English frequency text gate so generic local sentence/translation templates become `review_required` instead of accepted export content.
- Wired runtime text generation to provider-backed adapters: LiteLLM for example sentences when configured, DeepL for sentence translations when configured, with local adapters retained for tests/fallback.
- Rebuilt the Russian Kaikki cache so `в` resolves to the preposition entry with IPA `[v]`, not the uppercase `восток` abbreviation.
- Fixed reusable audio asset materialization so reused word/sentence audio is persisted under the current job/item before export.
- Batched frequency lexical candidate and item-success persistence so full 3000-card lexical runs complete without per-item commits.
