| corpus fixture/data -> `TatoebaSentenceSource` | Untrusted external sentence text enters the pipeline. |
| `TatoebaSentenceSource` -> translation adapter | Selected fallback text crosses into normal translation generation. |
| generation pipeline -> persisted text record | Weak fallback output could otherwise be stored as accepted card text. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-quick-01 | T | `tatoeba_sentence_source.py` | mitigate | Apply deterministic hard filters before scoring; reject questions, fragments, and meta-like content before any fallback sentence is emitted. |
| T-quick-02 | I | `text_generation.py` / translation flow | mitigate | Discard Tatoeba translation payloads and always build `SentenceTranslationRequest` from the selected sentence only. |
| T-quick-03 | D | `generate_text_items.py` repair loop | mitigate | Keep the fallback bounded to one repair attempt per D-06 so bad corpus results cannot create repeated retry loops. |
| T-quick-04 | R | persisted review state | mitigate | Preserve provenance `source="tatoeba"` plus existing validation/review flags so accepted vs review-required outcomes remain auditable. |
</threat_model>
