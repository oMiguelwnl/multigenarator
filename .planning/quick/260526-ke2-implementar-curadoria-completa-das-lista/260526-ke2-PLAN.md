<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| provider API -> local runtime | Untrusted provider exceptions, headers, usage metadata, and response metadata enter retry/telemetry code. |
| local/private text -> telemetry/report artifacts | Prompt inputs, highlight/private reading text, paths, and provider errors could leak into persisted logs or GSD artifacts. |
| wordfreq/bootstrap source -> committed frequency assets | External token stream is transformed into project-owned deck assets. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-260526-ke2-01 | Information Disclosure | provider telemetry/reporting | mitigate | Store prompt/response hashes and redacted `error_summary` only; tests assert raw secrets/private text are absent. |
| T-260526-ke2-02 | Tampering | frequency CSV assets | mitigate | Validate required schema, contiguous ranks, level counts, duplicates, provenance, and rejection reason codes in `scripts/build_frequency_assets.py --check` and pytest. |
| T-260526-ke2-03 | Denial of Service | provider retry loop | mitigate | Exponential backoff, Retry-After, capped attempts, and circuit breaker prevent immediate repeated calls after 403/429/timeout/network/server errors. |
| T-260526-ke2-04 | Repudiation | provider call attempts | mitigate | Persist one structured record per attempt with job/item/operation/provider/status/attempt/latency/error code when available. |
| T-260526-ke2-05 | Spoofing | provider metadata fields | accept | Provider/model/voice metadata is observability data from configured adapters, not an authorization boundary; no trust decision depends on it. |
</threat_model>
